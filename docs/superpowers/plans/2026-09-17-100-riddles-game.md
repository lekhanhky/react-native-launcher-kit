# 100 Câu Đố Kỳ Thú (100 Riddles Adventure) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây dựng hoàn chỉnh trò chơi giáo dục đa cấp độ "100 Câu Đố Kỳ Thú" với 100 câu thơ đố, bản đồ 5 vùng đất, 2 chế độ chơi (Mầm non bục 3D và Thám tử ghép chữ) cùng hệ thống thưởng rương kho báu hoàng kim.

**Architecture:** Kiến trúc module hóa cao độ: Ngân hàng dữ liệu tĩnh `riddles100Data.ts` (100 câu đố gieo vần, chia 5 world), dịch vụ lưu trữ bền vững `riddleService.ts` (MMKV), các component giao diện độc lập (`Riddle3DStageGrid`, `RiddleLetterScramble`, `RiddleWorldMapModal`, `RiddleTreasureModal`), kết nối trong màn hình trung tâm `RiddlesGameScreen.tsx` và tích hợp vào `KidsLauncherScreen.tsx`.

**Tech Stack:** React Native, TypeScript, React Native Reanimated / Animated, MMKV Storage, React Native Sound, VocabCard3DStage / Microsoft Fluent 3D pipeline.

**Spec:** `docs/superpowers/specs/2026-09-17-100-riddles-game-design.md`

## Global Constraints

- Không dùng thư viện bên ngoài mới mà tận dụng tối đa hệ thống sẵn có trong dự án (MMKV, Lucide Icons, VocabCard3DStage, sound effects).
- Đảm bảo 100% Type Safety (`npx tsc --noEmit` đạt 0 lỗi).
- Chạy mượt mà offline không cần mạng, tương thích tỉ lệ màn hình Android từ nhỏ đến lớn.
